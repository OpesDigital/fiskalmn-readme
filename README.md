# Fiskal MN

Cloud softver za **fiskalizaciju u Crnoj Gori** — usklađen sa Poreskom upravom CG. Izdavanje fiskalnih računa sa telefona, tableta ili računara, bez klasične fiskalne kase.

**Cijena:** od 13 € / mjesečno · nalog aktivan najčešće isti dan

## Šta nudi Fiskal MN

- Fiskalni računi u skladu sa zakonom (IIC, FIC, QR)
- Neograničen broj računa, kasa, korisnika i artikala
- Cloud pristup — telefon, tablet, PC
- Dnevni i periodični izvještaji
- **REST API** za e-commerce, booking i ERP integracije

## Za developere

Programska fiskalizacija preko REST API-ja:

- Base URL: `https://api.fiskalmn.me`
- Autentifikacija API ključem (`fk_test_` / `fk_live_`)
- Draft → fiskalizacija → IIC / FIC / broj računa / PDF

Detalji: **[Fiskal MN API Docs](https://docs.fiskalmn.me)**
